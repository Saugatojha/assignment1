What I Learned

through this assignment i learned how to structure a webpage using html. i also learned how css selectors work and how to apply different styles to different elements.

positioning was something new for me. fixed, relative, absolute and sticky all behave differently and this page shows all four of them working together.

forms were also a new thing. adding radio buttons, checkboxes and dropdowns made the feedback page feel more complete.

overall this assignment helped me understand how a real webpage is put together from scratch without using any extra tools or libraries.
